# CALCULADORA HUELLA DE CARBONO
Guía para en la creación de una mega calculadora de huella de carbono altamente funcional, aprovechando el poder de la inteligencia artificial a través de la herramienta Antigravity y Gemini 3 Pro. El proceso se centra en definir un prompt detallado que especifica tanto la investigación teórica como un diseño de interfaz moderno y animado, logrando resultados como el modo oscuro y efectos de glass morphism. La aplicación final no solo calcula las emisiones de CO2 generadas por varios modos de transporte, sino que también ofrece soluciones prácticas, como la cantidad de árboles necesarios para compensar y la promoción de los vehículos eléctricos como la mejor alternativa.

# CARBON-FOOTPRINT-CALCULATOR
## Overview
A guide for creating a highly functional mega carbon footprint calculator, leveraging the power of Artificial Intelligence through the Antigravity tool and Gemini 3 Pro.The process focuses on defining a detailed prompt that specifies both the theoretical research and a modern, animated interface design, achieving results like dark mode and glass morphism effects.The final application not only calculates the CO2 emissions generated by various modes of transport but also offers practical solutions, such as the number of trees needed for compensation and the promotion of electric vehicles as the best alternative.

## Before You Begin
* Make sure to install Google Antigravity; it's free.
* Ensure you have the necessary dependencies installed for the program to run, such as: Python, Typescript, etc.
* You might need Node.js, npm... if so, install everything required for the program to function correctly.
* The prompt is in English to obtain better results. You can translate and modify it for use in your language, and then translate it back to English with the changes.
* I have provided additional background images (in the +fondos folder) for you to experiment with composition and the harmony of colors, fonts, and themes.
* I have provided two prompt files. The first is for the basic, functional, and nice-looking calculator, but it lacks the complete design. The second (Electric...) contains the robust calculator.

If something is missing, refine it using the browser console (F12) or directly in the agent's instruction.
